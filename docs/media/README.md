# Preview sources

- `codex-inline-demo.gif` and `codex-inline.png`: passive screen captures from the dedicated **Widget demo** Codex chat on October 30, 2026. The GIF shows note entry, step changes, and the Send to chat button. It ends before the final feedback receipt. The capture is cropped to remove the sidebar and unrelated chats; widget pixels are not reconstructed.
- The six component PNGs: the shared renderer with `docs/examples/` inputs, generated by `benchmarks/render-demo.mjs`. The page header marks the local simulated chat bridge. These images are visual examples, not native feedback evidence.

Real Codex feedback was independently checked in the demo agent's next turn and saved receipt. Native Claude feedback has not been tested.
