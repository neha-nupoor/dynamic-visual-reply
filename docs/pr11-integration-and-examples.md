## Merge result

GitHub reported PR #11 mergeable into main, with no CI check runs listed. Both
PR #11 and PR #12 were drafts. A direct merge between their original heads had
two conflicts: the visual skill entrypoint and the renderer imports. PR #12 now
includes PR #11 as a merge parent. The resolution keeps the compact instructions,
adds the stack/grid guidance, and retains both the routing and card-sizing imports.

The simplest delivery is to merge the combined PR #12, which contains both sets
of changes. Alternatively, merge #11 with a merge commit, then merge #12.
An actual merge-tree simulation showed that squashing #11 into main first would
recreate the two conflicts because its commit identity changes; refresh #12 from
that new main before merging it in that sequence. No PR was merged into main as
part of this check. These are source/behavior checks, not a waiver of review policy.

## Table header repair

The user's screenshot exposed a gap in the earlier page-overflow test. At 320px,
Select had a 32px column and Name a 48px column. Global overflow-wrap:anywhere let
the browser split individual header words even though the page did not overflow.

Table headers now preserve word boundaries. Data columns have a 120px minimum,
selection 64px and feedback 190px. Review tables scroll inside their existing
container when narrow. Placement estimates use matching minimum widths and send
three-column read-only tables to standalone when 320px cannot fit them. The bundle
was rebuilt; draft/feedback versions and schemas were not changed for this fix.

The dedicated regression failed before the repair and passes 30 combinations
(five adapter IDs × two modes × 320/375/736px). It checks individual text ranges
for broken words, page overflow, narrow review scrolling and sortable headers.
The installed renderer and width estimator were updated after guarded comparison
with the PR #11 source; backups were retained.

Checks: 90 Node tests pass. The combined PR #11 layout passed 100 browser
layout/interaction checks and the existing read-only checks. Live examples passed
15 selector states across three widths, plus shared-view detail expansion and no
page overflow. Host bridges remain simulated; no new native submission claim is
made. After the header repair, targeted table checks cover all adapter IDs/modes.
